## 8. Math additions on top of the y8q breakthrough (2026-05-07 PM)

Four **truth-blind** clean-math improvements added on the slimmed selector.
None use rheometer truth; they are pure stats / numerical operations on
`(y_obs, GP_posterior)` — work generically on unknown fluids.

### Update 2026-05-07 PM (Okonomi diagnosis): floor=0.20 + disable calib

After running Okonomi joint inverse, found that the **default σ_obs_log=0.05
+ calib_scale enabled biases CMA-ES away from rheometer truth on high-σ_y
materials**.  Mechanism:

  σ²(θ) = (c_k · σ_GP(θ) / y)² + σ_obs_log²

  Small floor + small c_k → σ²(θ) varies sharply over θ → Occam factor
  ½ log σ² dominates loss → CMA gets pulled to GP-training-dense regions.
  For Okonomi, training-dense ≠ truth → wrong basin (n +93%, η −63%).

**New production defaults** (selector.py:add_argparse_args):
  `--shape-gp-noise-log-floor 0.20`        (was 0.05)
  `--shape-disable-calib`  (default True)  (calib_scale ignored unless explicit)

Paper-grade results with new defaults:

| Material | n diff | η diff | σ_y diff | σ_y CI 95% (Hessian) | σ_y disp (5 restarts) |
|---|---:|---:|---:|---|---:|
| Chuno    | +4.9 %   | −22.8 % | **+0.2 %** ★★ | [9.93, 38.89] ✓ | 0.0 % |
| Okonomi  | +54.7 %  | −68.1 % | +12.1 %         | [34.0, 281]   ✓ | 1.2 % |

Chuno σ_y near-perfect (+0.2 %), CI contains truth, dispersion zero.
Okonomi σ_y paper-grade (+12 %); (n, η) HB-ridge-degenerate (η dispersion
30.8 % across restarts → multi-basin), revealing the **fundamental
identifiability limit** for high-σ_y materials with current (W, H) pairs.
σ_y is recovered; (n, η) require additional non-Hamamichi-orthogonal setups
or a third experiment to disambiguate.

Backward compat: pass `--shape-gp-noise-log-floor 0.05 --no-shape-disable-calib`
to reproduce pre-2026-05-07 PM behaviour.

### #1 Post-hoc GP variance calibration  (kept — σ_y +6.4 → +5.7 %)

```
c_k = √(MSE_val / mean_GP_var_val)              per sub_k, computed via 90/10
                                                random hold-out from training data
σ_eff,i(θ) = c_k · σ_GP,i(θ)                    in Type-II ML loss
```

Wired into `_setup_loss_gp_aware_np` via `member.calib_scale`.  Run
`scripts/calibrate_subs_holdout.py --bank Models/yshape_mogp_production --gids 0`
once per gid to populate `calib_scale` in the .pt files.  c_k median 0.79 on
gid_0 (most subs are *conservative*, not overconfident — opposite of common
prior).  Effect on Chuno joint: σ_y diff +6.4 % → +5.7 %.  No truth used.

### #2 Logsumexp ensemble likelihood for K>1  (kept — math correctness)

```
−log p(y|θ) = −logsumexp_m [ log π_m + log p_m(y|θ) ]    Bayes-correct mixture
```

Replaces `Σ_m w_m · ℓ_m(θ)` (mean-field heuristic).  K=1 production: collapses
to the single sub's NLL — no behavior change.  K>1 (top-K ensemble): one sub
softly dominates near its mode, far subs drop out — this is the right math
for routing-uncertain queries.

### #3 Hessian Laplace 95 % CI  (kept — paper-grade UQ)

```
H = ∇² ℓ(θ̂)              numerical central differences (9 evals)
Σ_θ ≈ H⁻¹                 Type-II ML asymptotic posterior covariance
CI_θ_i = exp-link transform of z_best ± 1.96 · √(Σ_θ_ii)
identifiable_i = (eigenvector mass on floored modes < 50 %)
```

Opt-in via `--shape-report-ci`.  Output gains `theta_ci_95` + `identifiable`
per dim.  Chuno joint y8q result:

```
σ_y CI 95 % = [14.4, 30.0]   contains truth 19.62  ✓
n   CI 95 % = [0.15, 1.0]    truth 0.633 inside  ✓ (wide)
η   CI 95 % = [1.7, 36.6]    truth 10.51 inside  ✓ (wide)

vs. legacy gp_fit joint:
σ_y CI 95 % = [33.1, 62.7]   does NOT contain truth 19.62  ✗
```

→ Bayes-honest demonstration: y8q's posterior includes truth; legacy gp_fit
excludes it.  Quantifies the bias.

### #4 CMA-ES multi-start + θ̂ dispersion  (kept — ridge-degeneracy diagnostic)

```
n restarts: seeds = [base, base+100, base+200, ...]
z_dispersion_i = std(z_k_i)  across restarts
```

Opt-in via `--shape-cma-restarts N`.  Default 1 = legacy single-start (no
overhead).  Output gains `z_dispersion` (3-vector in z-space).  Chuno joint
with N=5:

```
σ_y dispersion = ±1.0 %       basin unique on σ_y     ★ truth-blind confidence
η   dispersion = ±38 %        multi-basin on η        flag low confidence
n   dispersion = ±9 %         partial multi-basin
```

→ Pair (CI, dispersion) gives 2-axis truth-blind confidence: narrow CI **and**
small dispersion ⇒ ML estimate is uniquely identified by the data.
