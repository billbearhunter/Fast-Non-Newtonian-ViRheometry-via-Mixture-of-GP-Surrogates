# 方法 — 通过 Mixture-of-GP 代理逆问题从相机观测快速测定非牛顿流变学

本文档为论文 *Methods* 章节草稿。每个章节内部将数学理论与代码实现明确分开：理论子章节给出数学公式与论文引用；实现子章节指向具体代码模块。实证验证与局限性分别见 [`RESULTS_2026-05-07.md`](RESULTS_2026-05-07.md) 与 [`DISCUSSION_2026-05-07.md`](DISCUSSION_2026-05-07.md)。

---

## 1. 概述

我们从两次释放-展布相机实验中恢复非牛顿流体的 Herschel-Bulkley 参数 **θ = (n, η, σ_y)** [Herschel & Bulkley 1926; Hamamichi et al. 2023]。流程是 4 阶段 Bayesian inverse：

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│ 相机得到的       │ →  │ 分层             │ →  │ 通过 batched    │ →  │ θ̂ + 95 % CI    │
│ y_obs           │    │ MoGP-rBCM        │    │ 5-restart       │    │ + dispersion    │
│ (8 帧 × 2 setup) │    │ 代理 (forward)   │    │ CMA-ES Type-II  │    │ (Bayes-honest   │
│                 │    │                 │    │ ML inverse      │    │  UQ 输出)       │
└─────────────────┘    └─────────────────┘    └─────────────────┘    └─────────────────┘
```

GP 混合代理 [Tresp 2000; Deisenroth & Ng 2015; Rasmussen & Williams 2006] 替代了过慢的 Material Point Method (MPM) [Sulsky et al. 1994] 正向模拟; CMA-ES [Hansen & Ostermeier 2001; Hansen 2016] 在 ~30 ms / forward call 完成 inverse。

## 2. 实验观测

### 2.1 Setup 几何

矩形容器宽 *W* (cm)、高 *H* (cm) 装入测试流体（密度 ρ）。在 *t = 0* 时前闸门释放; 流体在重力下向前展布。一台标定过的侧视相机捕获 8 个等间距帧（*t = t₁ … t₈*）。释放-展布协议遵循 Hamamichi et al. [2023]。

### 2.2 y_obs 向量

对每帧 *i*，通过剪影分割 + 相机标定投影提取最前流距 *y_i* (cm)。8 个标量距离构成 **y_obs ∈ ℝ⁸**，作为 Bayesian likelihood 的数据向量。

**实现：** `Calibration/extract_flow_distance.py`、`Calibration/build_y_obs.py`。

### 2.3 双 setup 设计

每种材料在 **两个不同 (W, H) 对** 下观测。Setup 1 由用户选择; Setup 2 是 analytical Hessian-orthogonal 提议（§6）。两个互补 setup 的选择最大化 Fisher 信息 [Hamamichi et al. 2023]。

## 3. Forward 代理: 分层 MoGP-rBCM

### 3.1 理论

MPM forward map *θ → y_obs* 太慢（≳ 35 h/材料）不适合在线 inverse，所以我们用分层 GP 专家混合 [Rasmussen & Williams 2006, 第 5 章] 来近似。每个专家是带 Matern 2.5 ARD 核 [Stein 1999; Neal 1996] 的 ExactGP 回归器。

为了 tractability，我们把输入空间 *(W, H, n, log η, log σ_y)* 切成 ~25 个不相交几何 bin (gid) [step L1]，每个 gid 内通过 K-means 聚类 [MacQueen 1967] 在 PCA [Pearson 1901; Hotelling 1933] 嵌入的 (shape + length) 特征空间中再切成 ~24-66 个 sub 专家 [step L2-L3]。robust Bayesian Committee Machine [Tresp 2000; Deisenroth & Ng 2015] 公式让一次 query 路由到 **一个** 活跃专家而不做 inter-expert variance aggregation，牺牲了 expert 间平滑性换取 forward 速度。

### 3.2 三层 routing（数学）

给定 query *(W, H, y_obs)*：

```
L1  几何 router:        gid = KNN[(W, H)]                    ∈ {0..24}
                         (训练 (W,H) bin 上的 KNN classifier)
L2  Cluster KMeans:     cluster = argmin_c ‖feat − μ_c‖²
                         feat = [w · log y_obs[7], PC₁(shape), PC₂, PC₃]
                         shape = (y_obs[1:8] − y_obs[0]) / (y_obs[7] − y_obs[0])
                         w  = y8_weight = 5.0  (length:shape 平衡)
L3  σ_y-quantile sub:   sub = argmin_k |y_obs[7] − ŷ8_med_k| / ŷ8_std_k
                         (Bayes-evidence sub 选择 — 见 §3.3)
```

### 3.3 L3 动机: y8-quantile 作为 1-D Bayes 模型选择

L1+L2 锁定几何与 shape regime 后，cluster 内的 sub 专家差异主要在 σ_y bin。把 sub *k* 内训练 y₈ 值的分布近似为 Gaussian (μ_k, σ_k)。在 1-D Gaussian 观测模型下，候选 sub *k* 的负对数边际似然为 [Murphy 2012, §5.3; MacKay 2003, 第 28 章]：

$$
-\log p(y_{\text{obs},7} \mid \text{sub}_k)
\;\approx\; \frac{(y_{\text{obs},7} - \mu_k)^2}{2 \sigma_k^2} + \tfrac12 \log \sigma_k^2
$$

在候选 sub 上取 *argmin* 是 **基于最终流距边际证据的标准 Bayes 模型选择** — 一般 Bayesian model-evidence ratio 的 1-D 特例。routing 时不需要 GP forward calls。

### 3.4 Per-sub ExactGP

每个 sub 持有 8 个独立的 ExactGP 回归器（每帧 *i = 1…8* 一个）带 Matern 2.5 ARD 核 [Stein 1999]，定义在 5-D 输入 *z_5 = (n, log η, log σ_y, W, H)*（标准化后）上。超参通过最大边际似然（Type-II MLE [Rasmussen & Williams 2006, §5.4.1]）由 Adam [Kingma & Ba 2015] 学习，最多 200 iterations。

**实现：** `surrogate/experts.py:ExactExpert.fit`。

### 3.5 训练数据

每个 sub: *N ∈ [200, 1000]* 个 MPM 模拟，由 Latin-hypercube [McKay et al. 1979] 在 θ-空间采样，对 σ_y-degenerate 区域用 active-learning infill。我们用 MLS-MPM 变体 [Hu et al. 2018] 做正向模拟。

**实现：** `surrogate/partition_v10_yshape.py`（训练数据 partitioner）、`scripts/partition_flat_kmeans.py`（生产 v2 partition）、`surrogate/train_yshape_subs.py`（训练循环）。

### 3.6 Post-hoc GP 方差校准

Per-sub 标量 *c_k = √(MSE_val / mean σ²_GP,val)* 由 sub 自己训练数据的 90/10 holdout 计算。推理时校准过的 std *σ_eff = c_k · σ_GP*。校准遵循深度学习校准文献 [Kuleshov et al. 2018]，特化为 per-sub 标量保持模型轻量。**生产中默认禁用 c_k**（理由见 §4.3）。

**实现：** `scripts/calibrate_subs_holdout.py`。

### 3.7 生产模型 state

Bank: `Models/v10_yshape_planB/state_gid_{0..24}/`。每个 gid 包含 `state.pkl`（partition meta）、`sub_assignments.csv`（训练点 → sub 映射）、`experts/sub_NNNN.pt`（per-sub state_dict + X_phys + Y_phys + calib_scale）。

## 4. Type-II ML inverse: GP-aware likelihood

### 4.1 理论: heteroscedastic Gaussian likelihood + Occam factor

我们假设状态相关方差的 Gaussian 观测模型 [Rasmussen & Williams 2006, §5.5; Murphy 2012, §15.2.6]：

$$
\log y_{\text{obs},i} = \log \hat{y}_i(\theta) + \varepsilon_i + \delta_i,\quad
\varepsilon_i \sim \mathcal{N}\!\big(0, \,(\sigma_{\text{GP},i}/\hat{y}_i)^2\big),\ 
\delta_i \sim \mathcal{N}\!\big(0,\,\sigma_{\text{obs,log}}^2\big)
$$

ε 是 GP 认知不确定度（GP 预测 std 通过 delta 法传播到 log-y 空间），δ 是测量噪声 floor。卷积得：

$$
\sigma_i^2(\theta) = \big(\sigma_{\text{GP},i}(\theta)/\hat{y}_i(\theta)\big)^2 + \sigma_{\text{obs,log}}^2
$$

负对数边际似然 — 也叫 Type-II ML 或 empirical Bayes loss [Rasmussen & Williams 2006, §5.4.1; Bishop 2006, §3.5] — per frame 是：

$$
-\log p(y_{\text{obs},i} \mid \theta) \;=\; \frac{r_i^2(\theta)}{2 \sigma_i^2(\theta)} + \tfrac12 \log \sigma_i^2(\theta) + \text{const}
$$

第一项是按精度加权的平方误差（类似 Mahalanobis 距离）; 第二项是 **Occam factor** [MacKay 2003, 第 28 章]，对高不确定度假设进行惩罚。没有 Occam factor，optimizer 会通过把 θ 漂到 σ_GP 大的区域（精度低）来"游戏"loss，因为那里任何残差都被不确定度"解释"。

### 4.2 Frame-weighted Type-II ML loss（完整形式）

加上 frame importance weight 与软 bbox 约束：

$$
\ell(\theta) \;=\; \frac{1}{n_f}\sum_{i=1}^{n_f}\Bigg[
\underbrace{\frac{w_i \, r_i^2(\theta)}{2\,\sigma_i^2(\theta)}}_{\text{Mahalanobis}} +
\underbrace{\tfrac12 \log \sigma_i^2(\theta)}_{\text{Occam factor}}
\Bigg] + w_{\text{sup}}\;\text{sup}(\theta)
$$

*r_i = log ŷ_i − log y_obs,i*、*w_i = frame_w_i² / σ_i²(θ)*、*frame_w = [0.2, 0.2, 0.35, 0.5, 0.8, 1.0, 1.4, 2.0]*（下调释放瞬态的早期帧权重，从前期工作继承未在此重新推导）、*sup(θ)* 是软-clamp 罚项保持 θ 在路由 sub 训练 bbox 内。

这是 **标准 Type-II ML / Empirical Bayes** — 零自由正则化超参。

**实现：** `Optimization/libs/selector.py:_setup_loss_log_nuisance_gp_np`（per-frame loss）、`inverse_single_shape` 与 `inverse_double_shape`（在 frames、members、setups 上的 loss 聚合）。

### 4.3 生产超参 default

```
shape_gp_noise_log_floor   = 0.20      (σ_obs_log)
shape_disable_calib        = True      (c_k 禁用，σ_eff = σ_GP)
```

**动机**: 小噪声 floor（如 0.05）+ active 校准（某些 sub c_k ~ 0.5）让 σ²(θ) 在 θ 上变化剧烈，使 Occam factor ½ log σ²(θ) 主导 loss。CMA-ES 因此漂向 GP-训练-密集区（σ_GP 小处），那不一定是 rheometer truth。实证（见 RESULTS）显示，0.20 floor + 禁用 calib 是 **唯一** 在 Chuno（低 σ_y）回收 σ_y 到 0.4 % 内**且** 在 Okonomiyaki（高 σ_y）回收到 12 % 的设置。低 floor + calib 给 Chuno σ_y +6.4 % **且** Okonomi (n, η) 灾难性偏离 HB ridge。

向后兼容: 传 `--shape-gp-noise-log-floor 0.05 --no-shape-disable-calib` 恢复 2026-05-07 之前行为。

### 4.4 理论: joint 双 setup likelihood

Setup *a, b* 在给定 θ 下条件独立（同一材料的不同实验），所以由 product rule [Murphy 2012, §2.2]：

$$
-\log p(y_a, y_b \mid \theta) \;=\; -\log p(y_a \mid \theta) - \log p(y_b \mid \theta)
\;=\; \ell_a(\theta) + \ell_b(\theta)
$$

单 setup loss 之**和**（不是平均）才是 Bayes-correct 形式 — 保持 joint Hessian rank 给出诚实的双数据源 CI。

### 4.5 实现: joint loss

实际形式：

$$
\ell_{\text{joint}}(\theta) = \ell_a(\theta) + \ell_b(\theta) + w_{\text{sup}} \cdot \tfrac12 (\text{sup}_a(\theta) + \text{sup}_b(\theta))
$$

**实现：** `Optimization/libs/selector.py:inverse_double_shape`。

### 4.6 理论: K > 1 ensemble (logsumexp 混合边际)

当 top-*K* > 1 个 sub 专家被路由时，ensemble member 上的 loss 是混合边际 NLL [Murphy 2012, §11.4]：

$$
-\log \sum_m \pi_m \, p_m(y \mid \theta)
\;=\; -\text{logsumexp}_m \big[\log \pi_m + \log p_m(y \mid \theta)\big]
\;=\; -\text{logsumexp}_m \big[\log \pi_m - \ell_m(\theta) \cdot n_f\big]
$$

这是 Bayes-correct 混合边际化。K = 1 退化为单 NLL，所以生产路径（K = 1）不变。

**实现：** `Optimization/libs/selector.py:_setup_nll_batched`。

## 5. CMA-ES 带 batched per-generation 评估

### 5.1 理论: CMA-ES

CMA-ES [Hansen & Ostermeier 2001; Hansen 2016] 是无导数进化优化器，自适应多变量正态采样分布到 loss landscape，适合代理诱导的非凸非光滑 Type-II ML loss surface。我们用标准 `(μ_W, λ)`-CMA 带 rank-μ + rank-1 协方差更新; 超参: popsize λ = 12、max iterations = 30、σ₀ = 0.25 (z 空间)。

**实现：** `cma` Python 库 [Hansen et al., https://github.com/CMA-ES/pycma]，从 `Optimization/libs/selector.py:_run_cma` 调用。

### 5.2 多起点带 dispersion 诊断

跑 *N_restarts = 5* 次独立 CMA-ES，seed 为 *(7 + sub_a · 100 + sub_b) + {0, 100, 200, 300, 400}*; 报告 lowest-loss θ̂ 和 **跨 restart 的标准差** 作为 truth-blind ridge-degeneracy 诊断。多起点 CMA 是公认的局部极小值防护 [Auger & Hansen 2005]。

```
σ_y dispersion < 5 %  → 单 basin, 1-restart 足够
                  > 20 % → 多 basin (e.g. HB ridge), 需要多 restart
```

### 5.3 理论: 通过 batched eval 摊销 launch overhead

每个 CMA-ES 代评估 *λ = 12* 个候选 z 的 loss。朴素实现做 12 次串行 GP forward → 12 × CUDA launch overhead (~37 ms 每次)。Batched 评估一次调用所有 12 个 z，利用 GP 对 batched test inputs 的天然支持 [Rasmussen & Williams 2006, §2.7]。Loss 聚合（Mahalanobis + Occam + logsumexp + sup penalty）是纯 CPU numpy，单次 GPU 调用之后 per-z 执行。

### 5.4 实现: batched eval

Loss 函数接受单个 z（shape (3,)）或 batch（shape (P, 3)）; 相应返回标量或 P 维向量。CMA 的 `es.ask()` 返回 λ 个 z 的列表，单次调用传给 loss。Hessian CI 计算（§7）用单 z 调 loss 得标量 — 向后兼容保留。

实证 wall-time 加速: joint inverse 上 8-13×; 见 Results §4。

**实现：** `Optimization/libs/selector.py:_run_cma`、`inverse_single_shape:loss`、`inverse_double_shape:_setup_nll_batched`。

## 6. 主动 setup-2 提议（Hamamichi-orthogonal）

### 6.1 理论: Fisher 信息 orthogonality

遵循 Hamamichi et al. [2023]，我们选 Setup 2 来最大化双 setup likelihood 的 **joint Fisher 信息**，等价于对齐两 setup 的主不确定度方向使它们约束 θ 空间中的正交方向 [Lehmann & Casella 1998, §6]。

对 Poiseuille 流下的 HB rheology，Fisher 矩阵在 (η, n, σ_y) 上有任意候选 (W, H) 的解析闭式，使得在候选 grid 上搜索不需要任何 forward 模拟。

### 6.2 流程

```
对每个已有观测 setup s_i:
    H_i = analytical_HB_Hessian(m̂, P_i, L_i)        (Hamamichi 2023)
    q_i = H_i 的主特征向量 (最大不确定度方向)

对 [2, 7] × [2, 7] cm 上 0.5-cm grid 的每个候选 (W, H):
    H_dash, q_dash = 候选处的相同量
    proj² = Σ_i (q_i · q_dash)²

(W*, H*) = argmin proj²
```

### 6.3 实现

`Optimization/libs/mechanism.py` — Hamamichi et al. [2023] 解析 proposer 的 verbatim port (`single_hessian` 给出闭式 Hessian、`propose_next_setup` 做 grid 搜索)。内部 CGS 单位; 生产中 (W, H) ∈ [2, 7] cm grid，0.5 cm 步长。

注意: 解析 Hessian 在 Poiseuille 通道流下计算，是对我们 重力驱动释放-展布实验的近似。见 DISCUSSION §2。

## 7. 不确定度量化

### 7.1 理论: Hessian Laplace 近似

收敛的 θ̂ 处，Bayesian posterior 由 Laplace 展开近似 [MacKay 2003, 第 27 章; Bishop 2006, §4.4]：

$$
p(\theta \mid y) \;\approx\; \mathcal{N}\big(\hat{\theta},\, H^{-1}\big),\quad H = \nabla^2 \ell(\hat{\theta})
$$

在正则性条件下对 Type-II ML 估计是渐近精确的 [Lehmann & Casella 1998, §6.4]。在我们的有限样本 HB-ridge 区段，近似是局部的但足够支持置信区间报告。

z 每维的 95 % credible interval 是 z_best ± 1.96·√[H⁻¹]_{ii}; (n, η, σ_y) CI 由 exp-link 变换得到。

### 7.2 实现: 数值 Hessian + identifiability flag

H 通过中心差分（3 对角 + 3 非对角，共 9 个额外 GP forward 评估）在 z_best 处用步长 *h_i = 0.10 · z_scale_i* 计算。低于 *0.01 · max|eval|* 的特征值被 floored 用于数值稳定（避免数据不约束某方向时 cov → ∞）。

per-dim **identifiability flag** 当且仅当该维特征向量在 floored 特征值上的质量 < 50 % 时为 True; False = 该维度被数据有效未识别。

**实现：** `Optimization/libs/selector.py:_hessian_ci`。

### 7.3 多 restart dispersion (truth-blind)

跨 5 个 CMA-ES restart 计算：

$$
z_{\text{disp},j} \;=\; \mathrm{std}\big[z_{\text{best}}^{(k)} \big]_{k=1..5,\,j}
$$

通过 exp-link 变换为物理单位相对 dispersion。提供 **basin-uniqueness 检查**，互补于局部 Hessian CI: 小 dispersion = 唯一全局最优; 大 dispersion = 多 basin loss landscape (e.g. HB ridge)。

### 7.4 组合 (CI, dispersion) 诊断

两个信号都 truth-blind（不需要 rheometer 数据），一起给出严谨 identifiability 报告：

```
窄 CI  + 低 dispersion  → 已识别，点估计可信
窄 CI  + 高 dispersion  → CI 低估不确定度（罕见; 调查）
宽 CI  + 低 dispersion  → 通过 routing-bbox 几何识别
                         (Hessian flat plateau)
宽 CI  + 高 dispersion  → 未识别，报告区间估计
```

## 8. 生产工作流

单材料，单 GPU 上 ~20 s wall-time：

```bash
# 1. 拍 setup1 帧 + camera_params.xml。提取 y_obs。
python -m Calibration.extract_flow_distance --dir ref_<mat>_<H>_<W>_1
python -m Calibration.build_y_obs            --dir ref_<mat>_<H>_<W>_1

# 2. Setup1 inverse + 提议 setup2。~10 s。
python -m Optimization.setup1 \
    --state-root Models/v10_yshape_planB \
    -f ref_<mat>_<H>_<W>_1 --density <ρ> \
    --shape-cma-restarts 5 --shape-report-ci

# 3. 在提议的 (W*, H*) 拍 setup2 帧。提取 y_obs。

# 4. Joint inverse 用 setup1 warm-start。~10 s。
python -m Optimization.setup2 \
    -f ref_<mat>_<H>_<W>_1 -s ref_<mat>_<H*>_<W*>_2 \
    --shape-warm-start-from-first \
    --shape-cma-restarts 5 --shape-report-ci
```

输出 (`<dir>/theta_hat.json`):

```jsonc
{
  "theta_hat":      {"n": ..., "eta": ..., "sigma_y": ...},
  "theta_ci_95":    {"n": [lo, hi], "eta": [lo, hi], "sigma_y": [lo, hi]},
  "identifiable":   {"n": bool, "eta": bool, "sigma_y": bool},
  "z_dispersion":   [σ_n, σ_log_η, σ_log_σ_y]
}
```
