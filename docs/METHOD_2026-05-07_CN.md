## 1. 概述

我们从 **S ≥ 2 次** 释放-展布相机实验中恢复非牛顿流体的 Herschel-Bulkley 参数 **θ = (n, η, σ_y)** [Herschel & Bulkley 1926; Hamamichi et al. 2023]，默认工作流为 S=2（一个用户选择 + 一个 Hamamichi-orthogonal 提议），S=3 无算法变化亦可用。流程是 4 阶段 Bayesian inverse：

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│ 相机得到的       │ →  │ 分层             │ →  │ 通过 batched    │ →  │ θ̂ + 95 % CI    │
│ y_obs           │    │ MoGP-rBCM        │    │ 5-restart       │    │ + dispersion    │
│ (8 帧 × 2 setup) │    │ 代理 (forward)   │    │ CMA-ES Type-II  │    │ (Bayes-honest   │
│                 │    │                 │    │ ML inverse      │    │  UQ 输出)       │
└─────────────────┘    └─────────────────┘    └─────────────────┘    └─────────────────┘
```

GP 混合代理 [Tresp 2000; Deisenroth & Ng 2015; Rasmussen & Williams 2006] 替代了过慢的 Material Point Method (MPM) [Sulsky et al. 1994] 正向模拟; CMA-ES [Hansen & Ostermeier 2001; Hansen 2016] 在 ~30 ms / forward call 完成 inverse。

## 2. 实验观测

### 2.1 Setup 几何

矩形容器宽 *W* (cm)、高 *H* (cm) 装入测试流体（密度 ρ）。在 *t = 0* 时前闸门释放; 流体在重力下向前展布。一台标定过的侧视相机捕获 8 个等间距帧（*t = t₁ … t₈*）。释放-展布协议遵循 Hamamichi et al. [2023]。

### 2.2 y_obs 向量（**本工作的新观测模态**）

对每帧 *i*，通过剪影分割 + 相机标定反投影到地平面提取最前流距 *y_i* (cm)。8 个 cm 量纲的距离构成 **y_obs ∈ ℝ⁸**，作为似然的数据向量。

> **与 [Hamamichi et al. 2023] 的差别**: Hamamichi 的"观测"是每帧 binarized ref vs binarized sim 的 pixel-XOR 异或像素计数比（见其 `GLRender3d/main.cpp:280-295` 的 `cv::bitwise_xor` + `(double)sumdiv/(width*height)`），最终 loss 是 8 个无量纲 scalar 的 `np.mean()`。我们用 cm-量纲流前距离作为每帧观测，是为了配合 GP database（每帧 distance 作为 GP 输出维度）+ 可与解析 Poiseuille 比较 + 可与 rheometer 单位对齐。

**实现：** `Calibration/extract_flow_distance.py`、`Calibration/build_y_obs.py`。

### 2.3 多 setup 设计（默认 S=2）

每种材料在 **S ≥ 2 个不同 (W, H) 对** 下观测。Setup 1 由用户选择; Setup 2 是 Hamamichi 解析 Hessian-orthogonal 提议（§7）。两个互补 setup 的选择最大化 Fisher 信息 [Hamamichi et al. 2023]。S = 3 无算法变化亦可用，由用户再添加一组几何即可（Tab. multi-setup 显示 S=1/2/3 的 σ_y 误差对比，1→3 σ_y 相对误差降到约 1/4）。

> **归属说明**: 多 setup 设计哲学和 Hessian-orthogonal 提议机制完全继承自 [Hamamichi et al. 2023]，本文不作为 method 贡献。我们的贡献是把这一设计变得 **联合（不是 sequential）求解** 且 **每材料几十秒内完成**（而不是几小时×N）。

## 3. 捕获-标定 pipeline

> **本工作贡献（§1 第 5 项）**: 一个单次调用的 Python pipeline
> (`Calibration/prepare_configs.py`)，替代了 [Hamamichi et al. 2023]
> 的 Premier Pro + fSpy + Blender + Photoshop 四工具人工流程。下面
> 每个算法阶段都是标准 CV 原语；本文贡献是**把整条链做成 robust +
> operator-light**，使一次实验从 raw video 到 $\mathbf{y}_{\text{obs}}$
> 只需 ~3 次用户点击，而不是一小时手动编辑。
>
> 详细数学 + 每步引用见
> [`Calibration/MATH.md`](../Calibration/MATH.md); 本节给 paper 用的
> 结构概述。

### 3.1 Pipeline 概览

```
input:  video.mov (24 fps) + background.JPG + settings.xml
                                                ↓
  (1) 帧抽取                    dam-break 检测; 按固定 cadence 取
                                config_00..config_08
                                                ↓
  (2) 相机内参                  ChArUco 板在 background frame 上标定
                                → K, 畸变 d
                                                ↓
  (3) 相机外参                  ChArUco prior + chamfer + IoU 边精修
                                匹配 config_00 容器立方体
                                                ↓
  (4) 剪影分割                  HSV 阈值 + ROI + 形态学
                                → 8 个二值掩膜
                                                ↓
  (5) 流前距离反投影             把最前流前像素经 (K, R, t) 反投影
                                到地平面 z=0
                                                ↓
output: 8 个 二值掩膜 (config_*.png)
        camera_params.xml (K, d, R, t)
        y_obs ∈ ℝ⁸ (cm)
```

### 3.2 帧抽取

8 帧 @ 24 fps 的节拍继承 [Hamamichi et al. 2023]。我们的自动化：基于
运动的 dam-break 事件检测扫视频, 提议一个 $t = 0$ 候选, 用户在 GUI
里确认（典型一次点击）。帧索引由 $t_0 + i / \text{fps}$ 算出, 通过
`ffprobe` 的 VFR-safe 时间戳查找处理非 CFR mp4 输入。

### 3.3 相机标定（内参 + 外参）

#### 3.3.1 内参: ChArUco 板拟合

ChArUco = 嵌入 ArUco 标记的棋盘; 子像素角点检测
[Garrido-Jurado et al. 2014, 2016] 即使部分遮挡也保持唯一对应关系。
相机内参 $K$ (焦距、主点) 和 5 参数 Brown 畸变 $\boldsymbol{d}$ 通过
Nelder–Mead [Nelder & Mead 1965] 在 background frame 上检测到的
ChArUco 角点上, 在针孔模型 [Hartley & Zisserman 2003] 下最小化重投影
误差拟合得到。

#### 3.3.2 外参: 边精修

ChArUco 内参拟合给出初始位姿 $(R_0, \boldsymbol{t}_0)$; 然后在 $K$
固定下优化 $(R, \boldsymbol{t})$, 把渲染的容器立方体剪影匹配到
dam-break frame `config_00`:

**阶段 1**（光滑, L-BFGS-B [Byrd et al. 1995; Zhu et al. 1997]）：
最小化加权 chamfer 距离

$$
\mathcal{L}_{\text{chamf}}(R, \boldsymbol{t}) =
\frac{1}{|\partial M_{\text{render}}|}
\sum_{\boldsymbol{p} \in \partial M_{\text{render}}}
d_{\text{EDT}}(\boldsymbol{p})
$$

其中 $\partial M_{\text{render}}$ 是渲染立方体剪影的边, $d_{\text{EDT}}$
是 `config_00` 的 Canny 边 [Canny 1986] 的欧氏距离变换
[Maurer et al. 2003]。$d_{\text{EDT}}$ 的双线性采样保持目标对 L-BFGS-B
足够光滑。

**阶段 2**（非光滑, Nelder–Mead）: 最大化渲染剪影与检测剪影的
pixel-IoU [Jaccard 1912]。旋转用 Rodrigues 指数映射
[Hartley & Zisserman 2003, §A6.6] 参数化; 对相对 ChArUco prior 的
$\|\Delta R\|$、$\|\Delta \boldsymbol{t}\|$ 设安全 clamp 防局部极小。

### 3.4 剪影分割

每帧的二值流体掩膜 $M_i$ 由以下产生:

1. HSV 颜色阈值（每材料的阈值范围）
2. 在 `config_08`（最展开帧）上画一次 ROI 多边形掩膜, 排除装置阴影
   与反射
3. 形态学闭运算 + 开运算 [Gonzalez & Woods 2018, 第 9 章] 去噪
4. 最大连通分量选择

### 3.5 流前距离反投影（y_obs 定义）

每个二值掩膜 $M_i$, 找出沿流方向 $\boldsymbol{e}_{\text{flow}}$ 的最前
流体像素:

$$
(u^\star_i, v^\star_i) \;=\; \arg\max_{(u,v) \in M_i} \,\langle (u, v),\, \boldsymbol{e}_{\text{flow}} \rangle
$$

经标定相机 $(K, R, \boldsymbol{t})$ 反投影到地平面 $z = 0$:

$$
(X_i, Y_i, 0) \;=\; \pi^{-1}_{(K, R, \boldsymbol{t}),\, z=0} (u^\star_i, v^\star_i)
$$

cm 量纲下沿 $\boldsymbol{e}_{\text{flow}}$ 自闸门基线的流前距离即
$y_i$。8 个距离构成 $\mathbf{y}_{\text{obs}} \in \mathbb{R}^8$
（其在似然中的角色见 §2.2 与 §5.1）。

## 4. Forward 代理: 分层 MoGP-rBCM

### 4.1 理论

MPM forward map *θ → y_obs* 太慢（≳ 35 h/材料）不适合在线 inverse，所以我们用分层 GP 专家混合 [Rasmussen & Williams 2006, 第 5 章] 来近似。每个专家是带 Matern 2.5 ARD 核 [Stein 1999; Neal 1996] 的 ExactGP 回归器。

为了 tractability，我们把输入空间 *(W, H, n, log η, log σ_y)* 切成 ~25 个不相交几何 bin (gid) [step L1]，每个 gid 内通过 K-means 聚类 [MacQueen 1967] 在 PCA [Pearson 1901; Hotelling 1933] 嵌入的 (shape + length) 特征空间中再切成 ~24-66 个 sub 专家 [step L2-L3]。robust Bayesian Committee Machine [Tresp 2000; Deisenroth & Ng 2015] 公式让一次 query 路由到 **一个** 活跃专家而不做 inter-expert variance aggregation，牺牲了 expert 间平滑性换取 forward 速度。

### 4.2 三层 routing（数学）

给定 query *(W, H, **y**)*, **y** = (y₁, …, y₈) ∈ ℝ⁸ 为流前距离观测：

$$
\begin{aligned}
\text{L1 (几何):} \quad &
g \;=\; \arg\min_{g \in \mathcal{G}} \,\| (W, H) - (W_g, H_g) \|
\\[2pt]
\text{L2 (聚类):} \quad &
c \;=\; \arg\min_{c} \, \| \boldsymbol{\phi}(\mathbf{y}) - \boldsymbol{\mu}_c \|^2,\quad
\boldsymbol{\phi}(\mathbf{y}) = \big( \lambda \log y_8,\, \pi_1,\, \pi_2,\, \pi_3 \big)
\\[2pt]
& \pi_j = \langle \mathbf{e}_j,\, \boldsymbol{s}(\mathbf{y}) \rangle,\quad
s_i(\mathbf{y}) = \frac{y_{i+1} - y_1}{y_8 - y_1}\ \text{for } i=1,\ldots,7
\\[2pt]
\text{L3 (sub 专家):} \quad &
k^\star \;=\; \arg\min_{k} \, \frac{|y_8 - \mu_{8,k}|}{\sigma_{8,k}}
\quad \text{(1-D Bayes evidence; 见 §4.3)}
\end{aligned}
$$

其中:
- $\mathcal{G}$ 是训练几何 bin 离散集（即 *gid*），L1 选择跟 query
  (W, H) 最近的几何 bin。
- $\boldsymbol{\phi}(\mathbf{y}) \in \mathbb{R}^4$ 是聚类特征:
  最终流距 $y_8$ 的对数（按 length-vs-shape 比例 $\lambda = 5$ 加权）
  加上归一化 shape 向量 $\boldsymbol{s}$ 的前三个主成分 $\pi_j$。
- $\boldsymbol{\mu}_c$ 是 L2 特征空间内预先算好的聚类质心,
  $\boldsymbol{e}_j$ 是预先算好的 PCA loading。
- $\mu_{8,k}, \sigma_{8,k}$ 是候选 sub 专家 $k$ 内训练 $y_8$ 值的
  经验均值/标准差。

### 4.3 L3 动机: 最终流距上的 1-D Bayes 模型选择

L1+L2 锁定几何与 shape regime 后, cluster 内的 sub 专家差异主要在
σ_y 范围上。设 $y_{8,k}^{(1)},\ldots,y_{8,k}^{(N_k)}$ 是候选 sub 专家
$k$ 内训练点的最终流距（$i = 8$）, 近似其分布为
$\mathcal{N}(\mu_{8,k}, \sigma_{8,k}^2)$。在该分布下, 观测 $y_8$ 的
负对数边际似然（去除加性常数）为 [Murphy 2012, §5.3; MacKay 2003,
第 28 章]:

$$
-\log p(y_8 \mid k)
\;\approx\; \frac{(y_8 - \mu_{8,k})^2}{2 \sigma_{8,k}^2} + \tfrac12 \log \sigma_{8,k}^2
$$

取 $k^\star = \arg\min_k$ 上式右端 = **基于最终流距边际证据的标准
Bayes 模型选择** — 一般 Bayesian model-evidence ratio 的 1-D 特例。
routing 时不需要 GP forward call, 只需预先算好的经验
$(\mu_{8,k}, \sigma_{8,k}^2)$ 统计量。

### 4.4 Per-sub ExactGP

每个 sub 持有 8 个独立的 ExactGP 回归器（每帧 *i = 1…8* 一个）带 Matern 2.5 ARD 核 [Stein 1999]，定义在 5-D 输入 *z_5 = (n, log η, log σ_y, W, H)*（标准化后）上。超参通过最大边际似然（Type-II MLE [Rasmussen & Williams 2006, §5.4.1]）由 Adam [Kingma & Ba 2015] 学习，最多 200 iterations。

**实现：** `surrogate/experts.py:ExactExpert.fit`。

### 4.5 训练数据

每个 sub: *N ∈ [200, 1000]* 个 MPM 模拟，由 Latin-hypercube [McKay et al. 1979] 在 θ-空间采样, 对早期 per-sub 拟合残差大的 σ_y-degenerate 区域做手动加密。我们用 MLS-MPM 变体 [Hu et al. 2018] 做正向模拟。
（系统性的 active-learning infill [Settles 2009] 列为 DISCUSSION §8 未来工作，当前 pipeline 不做）。

**实现：** `surrogate/partition_yshape.py`（训练数据 partitioner）、`scripts/partition_flat_kmeans.py`（生产 partition）、`surrogate/train_yshape_subs.py`（训练循环）。

### 4.6 Post-hoc GP 方差校准

Per-sub 标量 *c_k = √(MSE_val / mean σ²_GP,val)* 由 sub 自己训练数据的 90/10 holdout 计算。推理时校准过的 std *σ_eff = c_k · σ_GP*。校准遵循深度学习校准文献 [Kuleshov et al. 2018]，特化为 per-sub 标量保持模型轻量。**生产中默认禁用 c_k**（理由见 §5.3）。

**实现：** `scripts/calibrate_subs_holdout.py`。

### 4.7 生产模型 state

Bank: `Models/yshape_mogp_production/state_gid_{0..24}/`。每个 gid 包含 `state.pkl`（partition meta）、`sub_assignments.csv`（训练点 → sub 映射）、`experts/sub_NNNN.pt`（per-sub state_dict + X_phys + Y_phys + calib_scale）。

## 5. Type-II ML inverse: GP-aware likelihood

### 5.1 理论: heteroscedastic Gaussian likelihood + Occam factor

我们假设状态相关方差的 Gaussian 观测模型 [Rasmussen & Williams 2006, §5.5; Murphy 2012, §15.2.6]：

$$
\log y_{\text{obs},i} = \log \hat{y}_i(\theta) + \varepsilon_i + \delta_i,\quad
\varepsilon_i \sim \mathcal{N}\!\big(0, \,(\sigma_{\text{GP},i}/\hat{y}_i)^2\big),\ 
\delta_i \sim \mathcal{N}\!\big(0,\,\sigma_{\text{obs,log}}^2\big)
$$

ε 是 GP 认知不确定度（GP 预测 std 通过 delta 法传播到 log-y 空间），δ 是测量噪声 floor。卷积得：

$$
\sigma_i^2(\theta) = \big(\sigma_{\text{GP},i}(\theta)/\hat{y}_i(\theta)\big)^2 + \sigma_{\text{obs,log}}^2
$$

负对数边际似然 — 也叫 Type-II ML 或 empirical Bayes loss [Rasmussen & Williams 2006, §5.4.1; Bishop 2006, §3.5] — per frame 是：

$$
-\log p(y_{\text{obs},i} \mid \theta) \;=\; \frac{r_i^2(\theta)}{2 \sigma_i^2(\theta)} + \tfrac12 \log \sigma_i^2(\theta) + \text{const}
$$

第一项是按精度加权的平方误差（类似 Mahalanobis 距离）; 第二项是 **Occam factor** [MacKay 2003, 第 28 章]，对高不确定度假设进行惩罚。没有 Occam factor，optimizer 会通过把 θ 漂到 σ_GP 大的区域（精度低）来"游戏"loss，因为那里任何残差都被不确定度"解释"。

### 5.2 Frame-weighted Type-II ML loss（完整形式）

加上 frame importance weight 与软 bbox 约束:

$$
\ell(\theta) \;=\; \frac{1}{n_f}\sum_{i=1}^{n_f}\Bigg[
\underbrace{\frac{\alpha_i^2 \, r_i^2(\theta)}{2\,\sigma_i^2(\theta)}}_{\text{Mahalanobis}} +
\underbrace{\tfrac12 \log \sigma_i^2(\theta)}_{\text{Occam factor}}
\Bigg] + w_{\text{sup}}\,\Phi_{\text{sup}}(\theta)
$$

其中:
- $r_i(\theta) = \log \hat{y}_i(\theta) - \log y_{\text{obs},i}$ 是
  每帧 log 残差。
- $\boldsymbol{\alpha} = (\alpha_1, \ldots, \alpha_8) =
  (0.2, 0.2, 0.35, 0.5, 0.8, 1.0, 1.4, 2.0)$ 是**经验帧调度**, 渐进
  地加权后期帧, 用于吸收 real–sim gap（早期帧处于闸门释放瞬态, 渲
  染立方体剪影与捕获流体剪影差异最大 —— 闸门运动、释放时刻抖动、
  MPM forward 未建模的表面张力等; 后期帧进入稳定铺展段, 代理与真
  实最贴合）。
- $\Phi_{\text{sup}}(\theta) \ge 0$ 是软-clamp 罚项保持 θ 在路由 sub
  训练 bbox 内; $w_{\text{sup}} > 0$ 是其权重。

这是 **标准 Type-II ML / Empirical Bayes** — 零自由正则化超参。

**实现：** `Optimization/libs/selector.py:_setup_loss_gp_aware_np`（per-frame loss）、`inverse_single_setup` 与 `inverse_joint_setup`（在 frames、members、setups 上的 loss 聚合）。

### 5.3 生产超参 default

```
shape_gp_noise_log_floor   = 0.20      (σ_obs_log)
shape_disable_calib        = True      (c_k 禁用，σ_eff = σ_GP)
```

**动机**: 小噪声 floor（如 0.05）+ active 校准（某些 sub c_k ~ 0.5）让 σ²(θ) 在 θ 上变化剧烈，使 Occam factor ½ log σ²(θ) 主导 loss。CMA-ES 因此漂向 GP-训练-密集区（σ_GP 小处），那不一定是 rheometer truth。实证（见 RESULTS）显示，0.20 floor + 禁用 calib 是 **唯一** 在 Chuno（低 σ_y）回收 σ_y 到 0.4 % 内**且** 在 Okonomiyaki（高 σ_y）回收到 12 % 的设置。低 floor + calib 给 Chuno σ_y +6.4 % **且** Okonomi (n, η) 灾难性偏离 HB ridge。

向后兼容: 传 `--shape-gp-noise-log-floor 0.05 --no-shape-disable-calib` 恢复 2026-05-07 之前行为。

### 5.4 理论: joint multi-setup likelihood

S 个 setup *s = 1..S* 在给定 θ 下条件独立（同一材料的不同实验），所以由 product rule [Murphy 2012, §2.2]：

$$
-\log p(y_1, \ldots, y_S \mid \theta) \;=\; \sum_{s=1}^{S} -\log p(y_s \mid \theta) \;=\; \sum_{s=1}^{S} \ell_s(\theta)
$$

各 setup loss 之**和**（不是平均）才是 Bayes-correct 形式 — 保持 joint Hessian rank 给出诚实的多数据源 CI。生产默认 S=2; 实验中我们也评估了 S=1 和 S=3（见 RESULTS）。

### 5.5 实现: joint loss

实际形式（S 个 setup）：

$$
\ell_{\text{joint}}(\theta) = \sum_{s=1}^{S} \ell_s(\theta) + w_{\text{sup}} \cdot \tfrac{1}{S} \sum_{s=1}^{S} \text{sup}_s(\theta)
$$

**实现：** `Optimization/libs/selector.py:inverse_joint_setup`。当前顶层 CLI `Optimization.estimate_joint_setup` 接受两个 setup 路径; 推广到 S>2 只需扩展该 driver（核心 likelihood 已是 sum 形式）。

### 5.6 理论: K > 1 ensemble (logsumexp 混合边际)

当 top-*K* > 1 个 sub 专家被路由时，ensemble member 上的 loss 是混合边际 NLL [Murphy 2012, §11.4]：

$$
-\log \sum_m \pi_m \, p_m(y \mid \theta)
\;=\; -\text{logsumexp}_m \big[\log \pi_m + \log p_m(y \mid \theta)\big]
\;=\; -\text{logsumexp}_m \big[\log \pi_m - \ell_m(\theta) \cdot n_f\big]
$$

这是 Bayes-correct 混合边际化。K = 1 退化为单 NLL，所以生产路径（K = 1）不变。

**实现：** `Optimization/libs/selector.py:_setup_nll_batched`。

## 6. CMA-ES 带 batched per-generation 评估

### 6.1 理论: CMA-ES

CMA-ES [Hansen & Ostermeier 2001; Hansen 2016] 是无导数进化优化器，自适应多变量正态采样分布到 loss landscape，适合代理诱导的非凸非光滑 Type-II ML loss surface。我们用标准 `(μ_W, λ)`-CMA 带 rank-μ + rank-1 协方差更新; 超参: popsize λ = 12、max iterations = 30、σ₀ = 0.25 (z 空间)。

**实现：** `cma` Python 库 [Hansen et al., https://github.com/CMA-ES/pycma]，从 `Optimization/libs/selector.py:_run_cma` 调用。

### 6.2 多起点带 dispersion 诊断

跑 *N_restarts = 5* 次独立 CMA-ES，seed 为 *(7 + sub_a · 100 + sub_b) + {0, 100, 200, 300, 400}*; 报告 lowest-loss θ̂ 和 **跨 restart 的标准差** 作为 truth-blind ridge-degeneracy 诊断。多起点 CMA 是公认的局部极小值防护 [Auger & Hansen 2005]。

```
σ_y dispersion < 5 %  → 单 basin, 1-restart 足够
                  > 20 % → 多 basin (e.g. HB ridge), 需要多 restart
```

### 6.3 理论: 通过 batched eval 摊销 launch overhead

每个 CMA-ES 代评估 *λ = 12* 个候选 z 的 loss。朴素实现做 12 次串行 GP forward → 12 × CUDA launch overhead (~37 ms 每次)。Batched 评估一次调用所有 12 个 z，利用 GP 对 batched test inputs 的天然支持 [Rasmussen & Williams 2006, §2.7]。Loss 聚合（Mahalanobis + Occam + logsumexp + sup penalty）是纯 CPU numpy，单次 GPU 调用之后 per-z 执行。

### 6.4 实现: batched eval

Loss 函数接受单个 z（shape (3,)）或 batch（shape (P, 3)）; 相应返回标量或 P 维向量。CMA 的 `es.ask()` 返回 λ 个 z 的列表，单次调用传给 loss。Hessian CI 计算（§8）用单 z 调 loss 得标量 — 向后兼容保留。

实证 wall-time 加速: joint inverse 上 8-13×; 见 Results §3。

**实现：** `Optimization/libs/selector.py:_run_cma`、`inverse_single_setup:loss`、`inverse_joint_setup:_setup_nll_batched`。

## 7. 主动下一 setup 提议（Hamamichi-orthogonal，verbatim 继承）

> **归属**: 本节描述的提议机制 **完全继承自** [Hamamichi et al. 2023]; `Optimization/libs/mechanism.py` 是其闭式 Hessian + grid 搜索代码的逐字端口（verbatim port）。本工作不作为 method 贡献，仅在生产管线中调用。

### 7.1 理论: Fisher 信息 orthogonality

遵循 Hamamichi et al. [2023]，我们选下一 setup 来最大化联合 likelihood 的 **joint Fisher 信息**，等价于对齐已有 setup 的主不确定度方向与候选方向使它们约束 θ 空间中的正交方向 [Lehmann & Casella 1998, §5]。生产默认在 setup-1 上调用以提议 setup-2; S=3 时同样可在 (setup-1, setup-2) 联合 Hessian 上调用以提议 setup-3。

对 Poiseuille 流下的 HB rheology，Fisher 矩阵在 (η, n, σ_y) 上有任意候选 (W, H) 的解析闭式，使得在候选 grid 上搜索不需要任何 forward 模拟。

### 7.2 流程

对每个已有观测 setup $s_i$（在 Hamamichi 的 Poiseuille reduction 下用
压力 $P_i$ 和长度 $L_i$ 参数化）:

$$
H_i = H_{\text{HB}}(\hat{m},\, P_i,\, L_i),\qquad
\boldsymbol{q}_i = H_i \text{ 的主特征向量}
$$

其中 $H_{\text{HB}}$ 是 Poiseuille 通道流下 HB 参数的闭式 Fisher/
Hessian [Hamamichi et al. 2023], $\boldsymbol{q}_i$ 是 $\theta$ 空间的
最大不确定度方向。

对 $[2, 7]\times[2, 7]$ cm 上 0.5-cm grid 的每个候选 $(W, H)$, 计算
对应 $H'$、$\boldsymbol{q}'$, 并选择使候选特征向量到已有特征向量的
平方投影最小（正交性准则）的几何:

$$
(W^\star, H^\star) \;=\; \arg\min_{(W,H)} \, \sum_i \big(\boldsymbol{q}_i \cdot \boldsymbol{q}'(W, H)\big)^2
$$

### 7.3 实现

`Optimization/libs/mechanism.py` — Hamamichi et al. [2023] 解析 proposer 的 verbatim port (`single_hessian` 给出闭式 Hessian、`propose_next_setup` 做 grid 搜索)。内部 CGS 单位; 生产中 (W, H) ∈ [2, 7] cm grid，0.5 cm 步长。

注意: 解析 Hessian 在 Poiseuille 通道流下计算，是对我们 重力驱动释放-展布实验的近似。见 DISCUSSION §1。

## 8. 不确定度量化

### 8.1 理论: Hessian Laplace 近似

收敛的 θ̂ 处，Bayesian posterior 由 Laplace 展开近似 [MacKay 2003, 第 27 章; Bishop 2006, §4.4]：

$$
p(\theta \mid y) \;\approx\; \mathcal{N}\big(\hat{\theta},\, H^{-1}\big),\quad H = \nabla^2 \ell(\hat{\theta})
$$

在正则性条件下对 Type-II ML 估计是渐近精确的 [Lehmann & Casella 1998, §6.4]。在我们的有限样本 HB-ridge 区段，近似是局部的但足够支持置信区间报告。

z 每维的 95 % credible interval 是 z_best ± 1.96·√[H⁻¹]_{ii}; (n, η, σ_y) CI 由 exp-link 变换得到。

### 8.2 实现: 数值 Hessian + identifiability flag

H 通过中心差分（3 对角 + 3 非对角，共 9 个额外 GP forward 评估）在 z_best 处用步长 *h_i = 0.10 · z_scale_i* 计算。低于 *0.01 · max|eval|* 的特征值被 floored 用于数值稳定（避免数据不约束某方向时 cov → ∞）。

per-dim **identifiability flag** 当且仅当该维特征向量在 floored 特征值上的质量 < 50 % 时为 True; False = 该维度被数据有效未识别。

**实现：** `Optimization/libs/selector.py:_hessian_ci`。

### 8.3 多 restart dispersion (truth-blind)

跨 5 个 CMA-ES restart 计算：

$$
z_{\text{disp},j} \;=\; \mathrm{std}\big[z_{\text{best}}^{(k)} \big]_{k=1..5,\,j}
$$

通过 exp-link 变换为物理单位相对 dispersion。提供 **basin-uniqueness 检查**，互补于局部 Hessian CI: 小 dispersion = 唯一全局最优; 大 dispersion = 多 basin loss landscape (e.g. HB ridge)。

### 8.4 组合 (CI, dispersion) 诊断

两个信号都 truth-blind（不需要 rheometer 数据），一起给出严谨 identifiability 报告：

```
窄 CI  + 低 dispersion  → 已识别，点估计可信
窄 CI  + 高 dispersion  → CI 低估不确定度（罕见; 调查）
宽 CI  + 低 dispersion  → 通过 routing-bbox 几何识别
                         (Hessian flat plateau)
宽 CI  + 高 dispersion  → 未识别，报告区间估计
```

## 9. 生产工作流

单材料，单 GPU 上 ~20 s wall-time：

```bash
# 1. 拍 setup1 帧 + camera_params.xml。提取 y_obs。
python -m Calibration.extract_flow_distance --dir ref_<mat>_<H>_<W>_1
python -m Calibration.build_y_obs            --dir ref_<mat>_<H>_<W>_1

# 2. Setup1 inverse + 提议 setup2。~10 s。
python -m Optimization.estimate_first_setup \
    --state-root Models/yshape_mogp_production \
    -f ref_<mat>_<H>_<W>_1 --density <ρ> \
    --shape-cma-restarts 5 --shape-report-ci

# 3. 在提议的 (W*, H*) 拍 setup2 帧。提取 y_obs。

# 4. Joint inverse 用 setup1 warm-start。~10 s。
python -m Optimization.estimate_joint_setup \
    -f ref_<mat>_<H>_<W>_1 -s ref_<mat>_<H*>_<W*>_2 \
    --shape-warm-start-from-first \
    --shape-cma-restarts 5 --shape-report-ci
```

输出 (`<dir>/theta_hat.json`):

```jsonc
{
  "theta_hat":      {"n": ..., "eta": ..., "sigma_y": ...},
  "theta_ci_95":    {"n": [lo, hi], "eta": [lo, hi], "sigma_y": [lo, hi]},
  "identifiable":   {"n": bool, "eta": bool, "sigma_y": bool},
  "z_dispersion":   [σ_n, σ_log_η, σ_log_σ_y]
}
```
