# Method — Fast Non-Newtonian Rheology from Camera Observation via Mixture-of-GP Surrogate Inverse

This document describes the full inverse pipeline as it stands on 2026-05-07.
Treat as a draft of the paper's *Methods* section.

---

## 1. Overview

We recover the Herschel-Bulkley parameters
**θ = (n, η, σ_y)** of a non-Newtonian fluid from two release-and-spread
camera experiments, in **~20 s wall-time per material** with paper-grade
uncertainty quantification.  The pipeline is a four-stage Bayesian inverse:

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│ y_obs from      │ →  │ Hierarchical    │ →  │ Type-II ML      │ →  │ θ̂ + 95 % CI    │
│ camera          │    │ MoGP-rBCM       │    │ inverse via     │    │ + dispersion    │
│ (8 frames × 2   │    │ surrogate       │    │ batched 5-      │    │ (Bayes-honest   │
│  setups)        │    │ (forward model) │    │ restart CMA-ES  │    │  UQ output)     │
└─────────────────┘    └─────────────────┘    └─────────────────┘    └─────────────────┘
```

Surrogate replaces the prohibitively slow MPM forward simulation
(~35 h / single inverse on full MPM, Hamamichi 2023) with a hierarchical
mixture of Gaussian-process experts (~30 ms / forward call), enabling on-line
inverse at experimental cadence.

## 2. Experimental observation

### 2.1 Setup geometry

A rectangular reservoir with width *W* (cm) and height *H* (cm) is filled
with the test fluid (density ρ).  At *t = 0* the front gate is released;
the fluid spreads forward under gravity.  Eight evenly-spaced frames
(*t = t₁ … t₈*) are captured by a calibrated side-view camera.

### 2.2 y_obs vector

For each frame *i*, the front-most flow distance *y_i* (cm) is extracted by
silhouette segmentation + camera-calibrated projection
(`Calibration/extract_flow_distance.py`).  The eight scalar distances form
**y_obs ∈ ℝ⁸**.  We use *y_obs* as the Bayesian likelihood's data vector
(not the raw silhouette pixels, to suppress nuisance imaging variability).

### 2.3 Two-setup design

Following Hamamichi (2023), each material is observed at **two distinct
(W, H) pairs**.  Setup 1 is user-chosen; Setup 2 is the analytical
Hessian-orthogonal proposal of Setup 1's posterior
(`Optimization/libs/mechanism.py`, see §6.2).

## 3. Forward surrogate: hierarchical MoGP-rBCM

### 3.1 Three-layer routing

Given a query *(W, H, y_obs)*, the surrogate selects ONE active GP expert
("sub") via a deterministic three-layer routing:

```
L1  Geometric router:    gid = KNN[(W, H)]                  ∈ {0..24}
                         (25 disjoint (W,H)-bins, KNN classifier)
L2  Cluster KMeans:      cluster = argmin_c ‖feat − μ_c‖²
                         feat = [w · log y_obs[7], PC₁(shape), PC₂, PC₃]
                         shape = (y_obs[1:8] − y_obs[0]) / (y_obs[7] − y_obs[0])
                         w  = y8_weight = 5.0  (length:shape balance)
L3  σ_y-quantile sub:   sub = argmin_k |y_obs[7] − ŷ8_med_k| / ŷ8_std_k
                         (Bayes-evidence sub selection — see §3.2)
```

### 3.2 L3 motivation: y8-quantile as 1-D Bayes model selection

After L1+L2 fix the geometric and shape regime, sub-experts within a
cluster differ primarily in σ_y bin.  We exploit that the distribution of
training-data y₈ values within a sub is approximately Gaussian centred at
some μ_k, σ_k.  The negative-log-marginal-likelihood for the candidate
sub *k* under a 1-D Gaussian observation model is:

$$
-\log p(y_{\text{obs},7} \mid \text{sub}_k)
\;\approx\; \frac{(y_{\text{obs},7} - \mu_k)^2}{2 \sigma_k^2} + \tfrac12 \log \sigma_k^2
$$

Picking *argmin* over candidate subs is **standard Bayes model selection**
on the marginal evidence of the final flow distance.  No GP forward calls
required at routing time → **routing cost ~0.1 s per query**.

### 3.3 Per-sub ExactGP

Each sub holds **8 independent ExactGPs** (one per frame *i = 1…8*) with
Matern 2.5 ARD kernel over **z = (n, log η, log σ_y, W, H)** scaled.
Trained by Adam on `ExactMarginalLogLikelihood` for ≤ 200 iters per sub
(`surrogate/experts.py:fit`).

Training data per sub: *N ∈ [200, 1000]* MPM simulations sampled from a
Latin-hypercube grid over θ-space, with active-learning infill in
σ_y-degenerate regions.

### 3.4 Production model state

```
Models/v10_yshape_planB/state_gid_{0..24}/
  state.pkl                    partition meta (y8_weight=5.0, nc_v2)
  sub_assignments.csv          training point → sub mapping
  experts/sub_NNNN.pt          per-sub state_dict + X_phys + Y_phys + calib_scale
```

All 25 gids are v2-partitioned with Matern 2.5 ARD ExactGPs trained on
the 415 k-point production bank.  3 gids (0, 10, 24) covering the
production experimental geometries are post-hoc calibrated via
`scripts/calibrate_subs_holdout.py` (90/10 holdout c_k); 17 additional
gids retrained 2026-05-07 PM.

## 4. Type-II ML inverse: GP-aware likelihood

### 4.1 Generative noise model

Given a candidate θ (in z-space), the surrogate predicts mean ŷ_i(θ) and
posterior std σ_GP,i(θ) for each frame *i*.  We model real-world
observation as:

$$
\log y_{\text{obs},i} = \log \hat{y}_i(\theta) + \varepsilon_i + \delta_i,\quad
\varepsilon_i \sim \mathcal{N}\!\big(0, \,(\sigma_{\text{GP},i}/\hat{y}_i)^2\big),\ 
\delta_i \sim \mathcal{N}\!\big(0,\,\sigma_{\text{obs,log}}^2\big)
$$

where ε is GP epistemic uncertainty (delta-method log-space std) and δ
is a measurement-noise floor (`σ_obs_log = 0.20`, see §4.3).
Convolution gives:

$$
\sigma_i^2(\theta) = \big(\sigma_{\text{GP},i}(\theta)/\hat{y}_i(\theta)\big)^2 + \sigma_{\text{obs,log}}^2
$$

### 4.2 Type-II ML loss

The negative log marginal likelihood (per frame, frame-weighted):

$$
\ell(\theta) \;=\; \frac{1}{n_f}\sum_{i=1}^{n_f}\Bigg[
\underbrace{\frac{w_i \, r_i^2(\theta)}{2\,\sigma_i^2(\theta)}}_{\text{Mahalanobis}} +
\underbrace{\tfrac12 \log \sigma_i^2(\theta)}_{\text{Occam factor}}
\Bigg] + w_{\text{sup}}\;\text{sup}(\theta)
$$

where *r_i = log ŷ_i − log y_obs,i*, *w_i = frame_w_i² / σ_i²(θ)*,
*frame_w = [0.2, 0.2, 0.35, 0.5, 0.8, 1.0, 1.4, 2.0]* (down-weights early
release-transient frames), and *sup(θ)* is a soft-clamp penalty that
keeps θ inside the routed sub's training bbox.

This is **standard Type-II ML / Empirical Bayes** under a Gaussian-noise
+ GP-epistemic generative model — zero free regularisation
hyperparameters.

### 4.3 σ_obs_log floor: production default 0.20

A **higher floor (0.20 vs 0.05) is required** to suppress an Occam-factor
bias toward GP-training-dense regions.  Mechanism: when σ_obs_log is
small, σ_i²(θ) varies sharply over θ, and ½ log σ²(θ) dominates the
loss → CMA-ES drifts toward regions where σ_GP is small (i.e. dense in
training), even if that's far from the rheometer truth.

Empirically, floor = 0.20 + disable post-hoc calib_scale is the
single setting that recovers σ_y to within 0.4 % on Chuno (low-σ_y) AND
12 % on Okonomiyaki (high-σ_y).  Lower floors give Chuno σ_y +6.4 %
(slightly off truth) and Okonomi σ_y −4.2 % (apparently better but with
catastrophic n = +93 %, η = −63 % → flowcurve 3× truth at γ̇ = 100).

### 4.4 Joint two-setup likelihood

Setups *a, b* are conditionally independent given θ, so:

$$
-\log p(y_a, y_b \mid \theta) = \ell_a(\theta) + \ell_b(\theta) + w_{\text{sup}} \cdot \tfrac12 (\text{sup}_a + \text{sup}_b)
$$

The **sum** (not average) of single-setup losses is the Bayes-correct
form — preserves the joint Hessian rank for honest two-data-source CI.

### 4.5 K > 1 ensemble (logsumexp)

When top-*K* > 1 sub-experts are routed (paper default K = 1, but K = 3
is used in some materials for active routing fallback), the loss across
ensemble members is the **mixture marginal NLL**:

$$
-\log \sum_m \pi_m \, p_m(y \mid \theta) = -\text{logsumexp}_m \big[\log \pi_m - \ell_m(\theta) \cdot n_f\big]
$$

This is Bayes-correct mixture marginalisation; K = 1 collapses to single
NLL identically, no behavior change for the production path.

## 5. CMA-ES with batched per-generation evaluation

### 5.1 Standard CMA-ES with bbox softclamp

CMA-ES (`cma` library, popsize = 12, max_iter = 30, σ₀ = 0.25) optimises
ℓ(θ) over the union of routed subs' training bboxes, padded by 10 %.

### 5.2 Multi-start (5-restart paper-grade)

Five independent CMA-ES runs with seeds *(7 + sub_a · 100 + sub_b) +
{0, 100, 200, 300, 400}*; report the lowest-loss θ̂ and the **dispersion**
(standard deviation across restarts) as a truth-blind ridge-degeneracy
diagnostic.

```
σ_y dispersion < 5 %  → unique basin, 1-restart sufficient
                  > 20 % → multi-basin, 5-restart needed (HB ridge)
```

### 5.3 Batched eval: 8-13× speedup

Each CMA-ES generation produces *popsize = 12* candidate z's.  Naive
implementation calls the loss function 12 times sequentially — each
incurring a full Python+CUDA launch overhead (~37 ms).  We instead call
`predict_full_batched(member, all_12_zs, ctx)` **once per member per
generation**, processing all 12 candidates' GP forwards in a single CUDA
kernel.  Pure numpy aggregation (Mahalanobis + Occam + logsumexp + sup
penalty) follows on CPU.

Empirical wall-time per joint inverse (5-restart):

| Material | Sequential | Batched | Speedup |
|---|---:|---:|---:|
| Chuno   | 65 s | **7.7 s** | 8.4× |
| Okonomi | 133 s | **10.0 s** | 13× |

Single-material paper-grade workflow (setup1 alone + joint, both 5-restart)
runs in **~20 s**.

## 6. Active setup-2 proposal (Hamamichi-orthogonal)

### 6.1 Analytical Poiseuille Hessian

Following Hamamichi (2023), the closed-form HB Hessian over (η, n, σ_y)
under Poiseuille channel flow at any candidate (W, H) is computed
analytically (`Optimization/libs/mechanism.py:single_hessian`).

### 6.2 Proposal procedure

```
For each existing observed setup s_i:
    H_i = single_hessian(m̂, P_i, L_i)
    q_i = principal eigenvector of H_i (max-uncertainty direction)

For each candidate (W, H) on a 0.5-cm grid over [2, 7] × [2, 7]:
    H_dash, q_dash = analogous quantities at the candidate
    proj² = Σ_i (q_i · q_dash)²

(W*, H*) = argmin proj²
```

The recommendation is the geometry whose dominant uncertainty direction
is most orthogonal to the union of all existing setups' uncertainty
directions — maximising joint Fisher information.

### 6.3 Limitation: Poiseuille ≠ release-spread physics

The analytical proposal uses Poiseuille flow physics; our experiment is
gravity-driven release-and-spread with a free surface.  For low-σ_y
materials (Chuno) the proposal happens to be near-optimal; for high-σ_y
materials (Okonomiyaki), Poiseuille's truth-orthogonal direction can
diverge from the true MPM-orthogonal direction.  This contributes to the
HB-ridge degeneracy in (n, η) for Okonomi joint inverse (see §8.2).

## 7. Uncertainty quantification

### 7.1 Hessian Laplace 95 % CI (Type-II ML asymptotic posterior)

At the converged θ̂, the Bayesian posterior is approximated by the
Laplace expansion:

$$
p(\theta \mid y) \;\approx\; \mathcal{N}\big(\hat{\theta},\, H^{-1}\big),\quad H = \nabla^2 \ell(\hat{\theta})
$$

H is computed by central finite differences (9 extra GP evals: 3 diag +
3 off-diag, 6 evals each).  The posterior z-std on each dim is
*√[H⁻¹]_{ii}*; the (n, η, σ_y) CI follows by exp-link transform.

A **per-dim identifiability flag** is True iff the dimension's
eigenvector mass on floored eigenvalues (those replaced by floor =
0.01 × max|eval| for numerical stability) is below 50 %.  Wide-but-flagged
CI = data does not constrain that direction; user should report a
confidence interval rather than a point estimate.

### 7.2 Multi-restart dispersion

Computed across 5 CMA-ES restarts:

```
z_dispersion = std([z_best^(k)]_{k=1..5})    in z-space
              ≈  std((n, log η, log σ_y))
```

Translates to physical-unit relative dispersion via exp-link.  Provides
a **basin-uniqueness check**: small dispersion = unique global optimum;
large dispersion = multi-basin = HB ridge degeneracy.

### 7.3 Combined (CI, dispersion) diagnostic

Both signals are **truth-blind** (computed without rheometer data) and
together give a rigorous identifiability report:

```
Narrow CI  + low dispersion  → identified, trustworthy point estimate
Narrow CI  + high dispersion → CI underestimates uncertainty (rare)
Wide CI    + low dispersion  → identification by routing-bbox geometry,
                                Hessian flat (e.g. Okonomi σ_y plateau)
Wide CI    + high dispersion → unidentified, report bracketed estimate
```

## 8. Empirical validation

### 8.1 Chuno (low-σ_y, single-basin)

Truth (rheometer fit, 25 °C): *(n, η, σ_y) = (0.633, 10.51, 19.62)*

```
Joint y8q (5-restart paper-grade):
  θ̂ = (0.664, 8.12, 19.65)        σ_y diff +0.2 %  ★★★ near-perfect
  σ_y CI 95% = [9.93, 38.89]       contains truth ✓
  σ_y dispersion = 0.0 %           basin unique
  η dispersion = 35 %              HB ridge in (n, η) but σ_y locked
```

Snapdiff Row 6 (`|MPM(θ̂) − MPM(truth)|×5`) is dim across all frames →
recovered θ̂ produces MPM physics indistinguishable from rheometer-truth
MPM at sub-pixel level.  Row 4 (`|Real − MPM(θ̂)|×5`) ≈ Row 5
(`|Real − MPM(truth)|×5`) → residual sim-real gap is the simulator's
intrinsic surface-tension limitation, *not* an inverse error.

### 8.2 Okonomiyaki (high-σ_y, multi-basin in n,η)

Truth: *(n, η, σ_y) = (0.502, 67.05, 87.24)*

```
Joint y8q (5-restart paper-grade):
  θ̂ = (0.777, 21.36, 97.80)       σ_y diff +12.1 %  paper-grade
  σ_y CI 95% = [34.0, 281]         contains truth ✓
  σ_y dispersion = 1.2 %           σ_y identified (geometric — sub-bbox overlap)
  η dispersion = 30.8 %            HB ridge multi-basin in (n, η)
```

σ_y is identified, (n, η) are HB-ridge degenerate.  This is a
**fundamental physics property** of high-σ_y materials under our chosen
(W, H) setup pair — not a surrogate-training artifact (we verified that
training density near truth is in fact higher for Okonomi than Chuno;
sparsity is not the cause).  Breaking it would require a third setup
with significantly different aspect ratio or shear-rate profile.

## 9. Production workflow (single material, ~20 s)

```bash
# 1. Capture setup1 frames + camera_params.xml.  Extract y_obs.
python -m Calibration.extract_flow_distance --dir ref_<mat>_<H>_<W>_1
python -m Calibration.build_y_obs            --dir ref_<mat>_<H>_<W>_1

# 2. Setup1 inverse + propose setup2.  ~10 s.
python -m Optimization.setup1 \
    --state-root Models/v10_yshape_planB \
    -f ref_<mat>_<H>_<W>_1 --density <ρ> \
    --shape-cma-restarts 5 --shape-report-ci

# 3. Capture setup2 frames at the proposed (W*, H*).  Extract y_obs.

# 4. Joint inverse with setup1 warm-start.  ~10 s.
python -m Optimization.setup2 \
    -f ref_<mat>_<H>_<W>_1 -s ref_<mat>_<H*>_<W*>_2 \
    --shape-warm-start-from-first \
    --shape-cma-restarts 5 --shape-report-ci
```

Output (`<dir>/theta_hat.json`):

```jsonc
{
  "theta_hat": {"n": 0.664, "eta": 8.12, "sigma_y": 19.65},
  "theta_ci_95": {
      "n":       [0.0,    1.0   ],
```

## 13. Limitations and open issues

1. **HB ridge for high-σ_y materials.**  σ_y is identified; (n, η) are
   on the HB ridge.  Joint two-setup at our chosen (W, H) pairs cannot
   disambiguate.  Mitigation: a third setup at very different aspect
   ratio (e.g., H/W ≫ 2 for shear-dominated profile) would target this
   gap, at the cost of an additional camera experiment.

2. **Poiseuille proposal mismatch.**  `propose_next_setup` uses analytical
   Poiseuille physics, not full release-and-spread MPM.  For low-σ_y
   materials this is a benign approximation; for high-σ_y, the
   recommended setup may not be optimally orthogonal in real MPM physics.

3. **Sim-real gap.**  Our simulator (Taichi MPM) does not include surface
   tension, transient release dynamics, or non-isothermal effects.  This
   manifests as a residual ~10 % MPM-vs-real discrepancy on flow
   distance, irrespective of inverse accuracy.  We report θ̂ that
   recovers rheology truth, *not* θ̂ that minimises MPM-real residual —
   the two are mutually exclusive given the sim-real gap.

4. **Calibration coverage.**  20/25 production gids are
   v2-partitioned and trained as of 2026-05-07; gids 20-22 are partial
   (training interrupted).  Materials whose (W, H) routes to gids 20-22
   need the retrain script resumed before inverse.

5. **Active-setup proposal does not yet use surrogate Hessian.**  We
   inherit the analytical Poiseuille proposal from Hamamichi.  A
   surrogate-Hessian-based proposal (computing ∇²ℓ on the GP at θ̂ for
   candidate (W, H)) would more accurately predict the joint Hessian's
   rank and is a natural future direction.
