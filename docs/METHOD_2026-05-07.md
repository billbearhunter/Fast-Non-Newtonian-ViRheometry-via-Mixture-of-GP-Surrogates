# Method — Fast Non-Newtonian Rheology from Camera Observation via Mixture-of-GP Surrogate Inverse

This document is the *Methods* section draft.  Math theory and code
implementation are kept separated within each section: theory subsections
state the mathematical formulation with paper citations; implementation
subsections point to the specific code modules.  Empirical validation
and limitations are in [`RESULTS_2026-05-07.md`](RESULTS_2026-05-07.md)
and [`DISCUSSION_2026-05-07.md`](DISCUSSION_2026-05-07.md).

---

## 1. Overview

We recover the Herschel-Bulkley parameters
**θ = (n, η, σ_y)** [Herschel & Bulkley 1926] of a non-Newtonian fluid
from two release-and-spread camera experiments [Hamamichi et al. 2023].
The pipeline is a four-stage Bayesian inverse:

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│ y_obs from      │ →  │ Hierarchical    │ →  │ Type-II ML      │ →  │ θ̂ + 95 % CI    │
│ camera          │    │ MoGP-rBCM       │    │ inverse via     │    │ + dispersion    │
│ (8 frames × 2   │    │ surrogate       │    │ batched 5-      │    │ (Bayes-honest   │
│  setups)        │    │ (forward model) │    │ restart CMA-ES  │    │  UQ output)     │
└─────────────────┘    └─────────────────┘    └─────────────────┘    └─────────────────┘
```

The mixture-of-Gaussian-process surrogate
[Tresp 2000; Deisenroth & Ng 2015; Rasmussen & Williams 2006] replaces
the prohibitively slow Material Point Method (MPM) [Sulsky et al. 1994]
forward simulation with hierarchical GP experts; CMA-ES
[Hansen & Ostermeier 2001; Hansen 2016] performs the inverse at
~30 ms / forward call.

## 2. Experimental observation

### 2.1 Setup geometry

A rectangular reservoir with width *W* (cm) and height *H* (cm) is filled
with the test fluid (density ρ).  At *t = 0* the front gate is released;
the fluid spreads forward under gravity.  Eight evenly-spaced frames
(*t = t₁ … t₈*) are captured by a calibrated side-view camera.  The
release-and-spread protocol follows Hamamichi et al. [2023].

### 2.2 y_obs vector

For each frame *i*, the front-most flow distance *y_i* (cm) is extracted
by silhouette segmentation + camera-calibrated projection.  The eight
scalar distances form **y_obs ∈ ℝ⁸**, used as the Bayesian likelihood's
data vector.

**Implementation:** `Calibration/extract_flow_distance.py`,
`Calibration/build_y_obs.py`.

### 2.3 Two-setup design

Each material is observed at **two distinct (W, H) pairs**.  Setup 1 is
user-chosen; Setup 2 is the analytical Hessian-orthogonal proposal
(§6).  The choice of two complementary setups maximises Fisher
information [Hamamichi et al. 2023].

## 3. Forward surrogate: hierarchical MoGP-rBCM

### 3.1 Theory

The MPM forward map *θ → y_obs* is too slow (≳ 35 h/material) for
on-line inverse, so we approximate it by a hierarchical mixture of
Gaussian-process experts [Rasmussen & Williams 2006, Ch. 5].  Each
expert is an exact GP regressor with Matern 2.5 ARD kernel
[Stein 1999; Neal 1996].

For tractability we partition the input space *(W, H, n, log η, log σ_y)*
into ~25 disjoint geometric bins (gids) [step L1] and within each gid
into ~24-66 sub-experts via K-means clustering [MacQueen 1967] of a
PCA [Pearson 1901; Hotelling 1933] embedding of (shape + length)
features [step L2-L3].  The robust Bayesian Committee Machine
[Tresp 2000; Deisenroth & Ng 2015] formulation lets one query route to
ONE active expert without joint variance aggregation, sacrificing
inter-expert smoothness for forward speed.

### 3.2 Three-layer routing (math)

Given a query *(W, H, y_obs)*:

```
L1  Geometric router:    gid = KNN[(W, H)]                  ∈ {0..24}
                         (KNN classifier on training (W,H) bins)
L2  Cluster KMeans:      cluster = argmin_c ‖feat − μ_c‖²
                         feat = [w · log y_obs[7], PC₁(shape), PC₂, PC₃]
                         shape = (y_obs[1:8] − y_obs[0]) / (y_obs[7] − y_obs[0])
                         w  = y8_weight = 5.0  (length:shape balance)
L3  σ_y-quantile sub:   sub = argmin_k |y_obs[7] − ŷ8_med_k| / ŷ8_std_k
                         (Bayes-evidence sub selection — see §3.3)
```

### 3.3 L3 motivation: y8-quantile as 1-D Bayes model selection

After L1+L2 fix the geometric and shape regime, sub-experts within a
cluster differ primarily in σ_y bin.  Treat the distribution of training
y₈ values within sub *k* as approximately Gaussian (μ_k, σ_k).  The
negative log marginal likelihood of the candidate sub *k* under a
1-D Gaussian observation model is
[Murphy 2012, §5.3; MacKay 2003, Ch. 28]:

$$
-\log p(y_{\text{obs},7} \mid \text{sub}_k)
\;\approx\; \frac{(y_{\text{obs},7} - \mu_k)^2}{2 \sigma_k^2} + \tfrac12 \log \sigma_k^2
$$

Picking *argmin* over candidate subs is **standard Bayes model selection
on the marginal evidence** of the final flow distance — a 1-D special
case of the general Bayesian model-evidence ratio.  No GP forward calls
required at routing time.

### 3.4 Per-sub ExactGP

Each sub holds 8 independent ExactGP regressors (one per frame
*i = 1…8*) with Matern 2.5 ARD kernel [Stein 1999] over the 5-D
input *z_5 = (n, log η, log σ_y, W, H)* (after standardisation).
Hyperparameters are learnt by maximum marginal likelihood
(Type-II MLE [Rasmussen & Williams 2006, §5.4.1]) via Adam
[Kingma & Ba 2015] for ≤ 200 iterations.

**Implementation:** `surrogate/experts.py:ExactExpert.fit`.

### 3.5 Training data

Per sub: *N ∈ [200, 1000]* MPM simulations sampled from a Latin-hypercube
[McKay et al. 1979] grid over θ-space, with active-learning infill in
σ_y-degenerate regions.  We use the MLS-MPM variant of MPM
[Hu et al. 2018] for forward simulation.

**Implementation:** `surrogate/partition_v10_yshape.py` (training-data
partitioner), `scripts/partition_flat_kmeans.py` (production v2
partition), `surrogate/train_yshape_subs.py` (training loop).

### 3.6 Post-hoc GP variance calibration

Per-sub scalar *c_k = √(MSE_val / mean σ²_GP,val)* computed from a
random 90/10 hold-out of the sub's own training data.  At inference,
calibrated std *σ_eff = c_k · σ_GP*.  The calibration follows the
deep-learning calibration literature [Kuleshov et al. 2018], specialised
to per-sub scalars to keep the model lightweight.  **In production we
disable c_k by default** (see §4.3 for the rationale).

**Implementation:** `scripts/calibrate_subs_holdout.py`.

### 3.7 Production model state

Bank: `Models/v10_yshape_planB/state_gid_{0..24}/`.  Each gid carries
`state.pkl` (partition meta), `sub_assignments.csv` (training-point →
sub mapping), and `experts/sub_NNNN.pt` (per-sub state_dict + X_phys +
Y_phys + calib_scale).

## 4. Type-II ML inverse: GP-aware likelihood

### 4.1 Theory: heteroscedastic Gaussian likelihood + Occam factor

We assume a Gaussian observation model with state-dependent variance
[Rasmussen & Williams 2006, §5.5; Murphy 2012, §15.2.6]:

$$
\log y_{\text{obs},i} = \log \hat{y}_i(\theta) + \varepsilon_i + \delta_i,\quad
\varepsilon_i \sim \mathcal{N}\!\big(0, \,(\sigma_{\text{GP},i}/\hat{y}_i)^2\big),\ 
\delta_i \sim \mathcal{N}\!\big(0,\,\sigma_{\text{obs,log}}^2\big)
$$

where ε is GP epistemic uncertainty (the GP's predictive std propagated
via the delta method to log-y space) and δ is a measurement-noise
floor.  Convolution gives:

$$
\sigma_i^2(\theta) = \big(\sigma_{\text{GP},i}(\theta)/\hat{y}_i(\theta)\big)^2 + \sigma_{\text{obs,log}}^2
$$

The negative log marginal likelihood — also called Type-II ML or
empirical Bayes loss [Rasmussen & Williams 2006, §5.4.1; Bishop 2006,
§3.5] — is, per frame:

$$
-\log p(y_{\text{obs},i} \mid \theta) \;=\; \frac{r_i^2(\theta)}{2 \sigma_i^2(\theta)} + \tfrac12 \log \sigma_i^2(\theta) + \text{const}
$$

The first term is squared-error weighted by precision (Mahalanobis-like
distance); the second is the **Occam factor** [MacKay 2003, Ch. 28]
that penalises high-uncertainty hypotheses.  Without the Occam factor
the optimiser would game the loss by drifting θ into regions of large
σ_GP (hence small precision) where any residual is "explained" by
uncertainty.

### 4.2 Frame-weighted Type-II ML loss (full form)

Including frame importance weights and a soft bbox constraint:

$$
\ell(\theta) \;=\; \frac{1}{n_f}\sum_{i=1}^{n_f}\Bigg[
\underbrace{\frac{w_i \, r_i^2(\theta)}{2\,\sigma_i^2(\theta)}}_{\text{Mahalanobis}} +
\underbrace{\tfrac12 \log \sigma_i^2(\theta)}_{\text{Occam factor}}
\Bigg] + w_{\text{sup}}\;\text{sup}(\theta)
$$

where *r_i = log ŷ_i − log y_obs,i*, *w_i = frame_w_i² / σ_i²(θ)*,
*frame_w = [0.2, 0.2, 0.35, 0.5, 0.8, 1.0, 1.4, 2.0]* (down-weights
early release-transient frames inherited from prior work and not
re-derived here), and *sup(θ)* is a soft-clamp penalty that keeps θ
inside the routed sub's training bbox.

This is **standard Type-II ML / Empirical Bayes** — zero free
regularisation hyperparameters.

**Implementation:** `Optimization/libs/selector.py:_setup_loss_log_nuisance_gp_np`
(per-frame loss), `inverse_single_shape` and `inverse_double_shape`
(loss aggregation across frames, members, setups).

### 4.3 Production hyperparameter defaults

```
shape_gp_noise_log_floor   = 0.20      (σ_obs_log)
shape_disable_calib        = True      (c_k disabled, σ_eff = σ_GP)
```

**Motivation**: with small noise floors (e.g. 0.05) and active
calibration (e.g. c_k ~ 0.5 for some subs), σ²(θ) varies sharply over θ,
making the Occam factor ½ log σ²(θ) dominate the loss.  CMA-ES then
drifts toward GP-training-dense regions (where σ_GP is small), which
are not generally the rheometer truth.  Empirically (see RESULTS), the
0.20 floor + disabled calib is the single setting that recovers σ_y to
within 0.4 % on Chuno (low-σ_y) AND 12 % on Okonomiyaki (high-σ_y).
Lower floors + calib give Chuno σ_y +6.4 % AND Okonomi (n, η)
catastrophically off the HB ridge.

Backward compatibility: pass `--shape-gp-noise-log-floor 0.05
--no-shape-disable-calib` to recover pre-2026-05-07 behaviour.

### 4.4 Theory: joint two-setup likelihood

Setups *a, b* are conditionally independent given θ (separate
experiments on the same material), so by the product rule
[Murphy 2012, §2.2]:

$$
-\log p(y_a, y_b \mid \theta) \;=\; -\log p(y_a \mid \theta) - \log p(y_b \mid \theta)
\;=\; \ell_a(\theta) + \ell_b(\theta)
$$

The **sum** (not average) of single-setup losses is the Bayes-correct
form — preserves the joint Hessian rank for honest two-data-source CI.

### 4.5 Implementation: joint loss

Practical form:

$$
\ell_{\text{joint}}(\theta) = \ell_a(\theta) + \ell_b(\theta) + w_{\text{sup}} \cdot \tfrac12 (\text{sup}_a(\theta) + \text{sup}_b(\theta))
$$

**Implementation:** `Optimization/libs/selector.py:inverse_double_shape`.

### 4.6 Theory: K > 1 ensemble (logsumexp mixture marginal)

When top-*K* > 1 sub-experts are routed, the loss across ensemble
members is the mixture marginal NLL [Murphy 2012, §11.4]:

$$
-\log \sum_m \pi_m \, p_m(y \mid \theta)
\;=\; -\text{logsumexp}_m \big[\log \pi_m + \log p_m(y \mid \theta)\big]
\;=\; -\text{logsumexp}_m \big[\log \pi_m - \ell_m(\theta) \cdot n_f\big]
$$

This is Bayes-correct mixture marginalisation.  K = 1 collapses to
single NLL identically, so the production path (K = 1) is unchanged.

**Implementation:** `Optimization/libs/selector.py:_setup_nll_batched`.

## 5. CMA-ES with batched per-generation evaluation

### 5.1 Theory: CMA-ES

CMA-ES [Hansen & Ostermeier 2001; Hansen 2016] is a derivative-free
evolutionary optimiser that adapts a multivariate normal sampling
distribution to the loss landscape, suitable for the non-convex,
non-smooth Type-II ML loss surface induced by the surrogate.  We use
the standard `(μ_W, λ)`-CMA with rank-μ + rank-1 covariance updates;
hyperparameters: popsize λ = 12, max iterations = 30, σ₀ = 0.25 in
z-space.

**Implementation:** the `cma` Python library
[Hansen et al., https://github.com/CMA-ES/pycma], called from
`Optimization/libs/selector.py:_run_cma`.

### 5.2 Multi-start with dispersion diagnostic

We run *N_restarts = 5* independent CMA-ES with seeds
*(7 + sub_a · 100 + sub_b) + {0, 100, 200, 300, 400}*; report the
lowest-loss θ̂ and the **standard deviation across restarts** as a
truth-blind ridge-degeneracy diagnostic.  Multi-start CMA is a
well-known guard against local minima [Auger & Hansen 2005].

```
σ_y dispersion < 5 %  → unique basin, 1-restart sufficient
                  > 20 % → multi-basin (e.g. HB ridge), multi-restart needed
```

### 5.3 Theory: amortising launch overhead via batched eval

Each CMA-ES generation evaluates the loss at *λ = 12* candidate z's.
Naive implementation makes 12 sequential GP forward calls → 12 × CUDA
launch overhead (~37 ms each).  Batched evaluation makes ONE call with
all 12 z's, leveraging the GP's natural support for batched test
inputs [Rasmussen & Williams 2006, §2.7].  Loss aggregation (Mahalanobis
+ Occam + logsumexp + sup penalty) is pure CPU numpy, performed
per-z after the single GPU call.

### 5.4 Implementation: batched eval

The loss function accepts either a single z (shape (3,)) or a batch
(shape (P, 3)); returns scalar or P-vector correspondingly.  CMA's
`es.ask()` returns a list of λ z's, passed in one call to the loss.
The Hessian CI computation (§7) calls the loss with single z and gets
scalar — backward compat preserved.

Empirical wall-time speedup: 8-13× on joint inverse; see Results §4.

**Implementation:** `Optimization/libs/selector.py:_run_cma`,
`inverse_single_shape:loss`, `inverse_double_shape:_setup_nll_batched`.

## 6. Active setup-2 proposal (Hamamichi-orthogonal)

### 6.1 Theory: Fisher-information orthogonality

Following Hamamichi et al. [2023], we choose Setup 2 to maximise the
**joint Fisher information** of the two-setup likelihood, equivalently
to align the principal uncertainty directions of the two setups so
they constrain orthogonal directions in θ-space [Lehmann & Casella
1998, §6].

For HB rheology under Poiseuille flow, the Fisher matrix has a
closed-form expression in (η, n, σ_y) at any candidate (W, H), allowing
candidate-grid search without any forward simulation.

### 6.2 Procedure

```
For each existing observed setup s_i:
    H_i = analytical_HB_Hessian(m̂, P_i, L_i)        (Hamamichi 2023)
    q_i = principal eigenvector of H_i (max-uncertainty direction)

For each candidate (W, H) on a 0.5-cm grid over [2, 7] × [2, 7] cm:
    H_dash, q_dash = analogous quantities at the candidate
    proj² = Σ_i (q_i · q_dash)²

(W*, H*) = argmin proj²
```

### 6.3 Implementation

`Optimization/libs/mechanism.py` — verbatim port of Hamamichi
et al. [2023]'s analytical proposer (`single_hessian` for the closed-form
Hessian, `propose_next_setup` for the grid search).  CGS units
internally; (W, H) ∈ [2, 7] cm grid with 0.5 cm step in production.

Caveat: the analytical Hessian is computed under Poiseuille channel
flow, an approximation to our gravity-driven release-and-spread
experiment.  See DISCUSSION §2.

## 7. Uncertainty quantification

### 7.1 Theory: Hessian Laplace approximation

At the converged θ̂, the Bayesian posterior is approximated by the
Laplace expansion [MacKay 2003, Ch. 27; Bishop 2006, §4.4]:

$$
p(\theta \mid y) \;\approx\; \mathcal{N}\big(\hat{\theta},\, H^{-1}\big),\quad H = \nabla^2 \ell(\hat{\theta})
$$

This is asymptotically exact for the Type-II ML estimator under
regularity conditions [Lehmann & Casella 1998, §6.4].  In our
finite-sample HB-ridge regime, the approximation is local but
sufficient for confidence-interval reporting.

The 95 % credible interval on each dim of z is z_best ± 1.96·√[H⁻¹]_{ii};
the (n, η, σ_y) CI follows by exp-link transform.

### 7.2 Implementation: numerical Hessian + identifiability flag

H is computed by central finite differences (3 diag + 3 off-diag, total
9 extra GP forward evals) at z_best with step
*h_i = 0.10 · z_scale_i*.  Eigenvalues below
*0.01 · max|eval|* are floored for numerical stability (avoids cov →
∞ when the data does not constrain a direction).

A per-dim **identifiability flag** is True iff the dimension's eigenvector
mass on floored eigenvalues is below 50 %; False = dimension is
effectively unidentified by the data.

**Implementation:** `Optimization/libs/selector.py:_hessian_ci`.

### 7.3 Multi-restart dispersion (truth-blind)

Computed across the 5 CMA-ES restarts:

$$
z_{\text{disp},j} \;=\; \mathrm{std}\big[z_{\text{best}}^{(k)} \big]_{k=1..5,\,j}
$$

Translates to physical-unit relative dispersion via exp-link.  Provides
a **basin-uniqueness check** that complements the local Hessian CI:
small dispersion = unique global optimum; large dispersion = multi-basin
loss landscape (e.g. HB ridge).

### 7.4 Combined (CI, dispersion) diagnostic

Both signals are truth-blind (no rheometer data needed) and together
give a rigorous identifiability report:

```
Narrow CI  + low dispersion  → identified, trustworthy point estimate
Narrow CI  + high dispersion → CI underestimates uncertainty (rare; investigate)
Wide CI    + low dispersion  → identification by routing-bbox geometry
                                (Hessian flat plateau)
Wide CI    + high dispersion → unidentified, report bracketed estimate
```

## 8. Production workflow

Single material, ~20 s wall-time on a single GPU:

```bash
# 1. Capture setup1 frames + camera_params.xml.  Extract y_obs.
python -m Calibration.extract_flow_distance --dir ref_<mat>_<H>_<W>_1
python -m Calibration.build_y_obs            --dir ref_<mat>_<H>_<W>_1

# 2. Setup1 inverse + propose setup2.  ~10 s.
python -m Optimization.setup1 \
    --state-root Models/v10_yshape_planB \
    -f ref_<mat>_<H>_<W>_1 --density <ρ> \
    --shape-cma-restarts 5 --shape-report-ci

# 3. Capture setup2 frames at the proposed (W*, H*).  Extract y_obs.

# 4. Joint inverse with setup1 warm-start.  ~10 s.
python -m Optimization.setup2 \
    -f ref_<mat>_<H>_<W>_1 -s ref_<mat>_<H*>_<W*>_2 \
    --shape-warm-start-from-first \
    --shape-cma-restarts 5 --shape-report-ci
```

Output (`<dir>/theta_hat.json`):

```jsonc
{
  "theta_hat":      {"n": ..., "eta": ..., "sigma_y": ...},
  "theta_ci_95":    {"n": [lo, hi], "eta": [lo, hi], "sigma_y": [lo, hi]},
  "identifiable":   {"n": bool, "eta": bool, "sigma_y": bool},
  "z_dispersion":   [σ_n, σ_log_η, σ_log_σ_y]
}
```
